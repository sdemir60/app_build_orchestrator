# Spinner

Başlangıç modundaki kesikli halkanın dönen hâli: r 6.7, desen 2.3 2.5, opaklık 0.9, 1.5 kontur, 1.4s lineer; reduced-motion'da durur. Uygulamada building spinner'ıdır (`BuildingSpinner`) ve bakım kutusunda çalışan düğmenin işaretinin yerine geçer; ayrı bir çizim değildir. Derleme statüsü için `StatusGlyph status="building"` (aynı çizim).

**Props:** `size` (px, 14) · `color` (varsayılan `amber-text`) · `title` (varsayılan `Loading`) · `style`.
