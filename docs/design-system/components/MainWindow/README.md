# MainWindow

Ana pencere UI kiti: toolbar, proje listesi, graf, konsol ve simüle Sync → Build akışı — sistemin bileşenlerinin birlikte kullanımı.

Bir vitrin sayfasıdır, tek başına yeniden kullanılacak bir bileşen değil. Örnek veri nötrdür (`ACME.*` projeleri, `Acme.sln`); kitin kendi arayüz metinleri paket bundle'ından gelir ve Türkçe kalmıştır. Gerçek uygulamanın yerleşimi, metni ve davranışı için v2.0.0 handoff'u ve uygulamanın kodu esastır.

**Props:** `logoBase` (logo dosyalarının klasörü; `delta-logo-dark.svg` içermeli).
