# Dialog

Modal dialog: düz scrim (`scrim`, blur yok), `surface-overlay` zemin, `radius-lg`, `elevation-overlay`.

**Tüketici sağlar:** `open`, `title`, `children` (gövde), `footer` (butonlar — birincil sağda), `onClose`; dialog en yakın konumlanmış kapsayıcıyı kaplar (`position: absolute; inset: 0`), kapsayıcı `position: relative` olmalı.

**Props:** `open` · `title` · `width` (440) · `onClose` · `footer` · `children` · `style`.
