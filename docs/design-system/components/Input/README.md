# Input

Tek satırlık metin girişi; `surface-sunken` zemin, odakta amber halka.

**Tüketici sağlar:** standart `input` prop'ları (`value`, `onChange`, `placeholder`); yollar ve sayılar için `mono`.

**Props:** `mono` · `invalid` (fail kenarlığı) · `prefix` (sol ikon/metin) · `style` + tüm input prop'ları.
