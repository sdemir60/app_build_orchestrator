# Chip

Filtre/seçim çipi: etiket + değer, isteğe bağlı açılır ok ya da kaldırma düğmesi.

**Tüketici sağlar:** `label`, `value`, isteğe bağlı `icon`; `chevron` (popover açar) ya da `onRemove` (filtreyi kaldırır).

**Props:** `icon` · `label` · `value` · `chevron` · `active` · `onRemove` · `disabled` · `style`. Değerler (branch, config) mono yazılmaz; sayılar mono.
