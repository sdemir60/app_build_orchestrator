# IconButton

Yalnız ikon taşıyan kare buton (araç çubuğu, title bar, satır eylemleri).

**Tüketici sağlar:** `children` = tek bir 14–16px stroke SVG (`currentColor`), mutlaka `title` (tooltip/erişilebilir ad).

**Props:** `size` `sm | md | lg` · `active` (seçili/aktif durum) · `disabled` · `title` · `style`. Hover: bir yüzey adımı; renk tonu değişmez.
