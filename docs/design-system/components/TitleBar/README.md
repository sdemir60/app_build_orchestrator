# TitleBar

Pencere başlık çubuğu (40px): logo, başlık, ortada serbest alan ve pencere düğmeleri.

**Tüketici sağlar:** `title`, `logoSrc` (dark UI logosu — ör. `delta-logo-dark.svg`; uygulamada ürün işareti 19px solda, firma wordmark'ı ayraçtan sonra 10px / %55 opaklık), `children` (ortadaki öğeler), `onMinimize` / `onMaximize` / `onClose`.

**Props:** `title` (varsayılan `Build Orchestrator`) · `logoSrc` · `children` · `onMinimize` · `onMaximize` · `onClose` · `style`.
