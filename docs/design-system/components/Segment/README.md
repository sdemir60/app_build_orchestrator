# Segment

Birbirini dışlayan 2–4 seçenek için segment kontrolü (ör. Debug / Release).

**Tüketici sağlar:** `options` (string ya da `{value,label}`), kontrollü `value` ve `onChange`.

**Props:** `options` · `value` · `onChange(value)` · `size` `sm | md` · `style`. Seçili segment `surface-overlay` zemin + `text-primary`.
