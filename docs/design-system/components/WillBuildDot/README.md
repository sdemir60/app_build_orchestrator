# WillBuildDot

8px will-build noktası: `dirty` amber dolu, `clean` gri, `unknown` içi boş halka.

**Not:** uygulamada ayrı will-build kanalı yoktur; 8px nokta görsel durum rengini taşır, başlangıç modunda dört yaylı halkadır. Bileşen ve `dot-*` token'ları uyumluluk için durur.

**Props:** `state` `dirty | clean | unknown` · `size` · `title` (bundle varsayılanı Türkçe açıklama) · `style`. Tokenlar: `dot-dirty`, `dot-clean`, `dot-unknown`, `dot-size`.
