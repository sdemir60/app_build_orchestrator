# Toolbar

Araç çubuğu (44px) ve yardımcıları `ToolbarSep` (dikey hairline) ve `ToolbarSpacer` (esnek boşluk).

**Tüketici sağlar:** `children` = butonlar, segmentler, çipler; gruplar arasına `ToolbarSep`, sağa yaslamak için `ToolbarSpacer`.

Uygulama penceresinde toolbar yoktur: şeritleri ribbon (32px) ve action bar'dır (42px).

**Props:** `Toolbar { children, style }` · `ToolbarSep { style }` · `ToolbarSpacer {}`.
