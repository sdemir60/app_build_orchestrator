# Field

Form alanı sarmalayıcı: etiket, ipucu ve hata metni + içerdiği kontrol.

**Tüketici sağlar:** `children` = bir kontrol (`Input`, `Select`, `Switch`…), `label`, isteğe bağlı `hint` / `error`, `htmlFor`.

**Props:** `label` · `hint` · `error` (hata metni `status-fail-text`) · `htmlFor` · `inline` (etiket solda) · `children` · `style`.
