# StatusBadge

Statü rozeti: glyph + metin + tonlu zemin — renk, glyph ve metin üçü birden.

**Tüketici sağlar:** `status`; isteğe bağlı `label` (bundle varsayılanı Türkçe statü adıdır; uygulamanın İngilizce kelimesini ver: `Up to date`, `To build`, `Queued`, `Building`, `Failed`) ve `detail` (süre, sayaç — mono).

**Props:** `status` · `label` · `size` `sm | md` · `detail` · `style`. Zemin `status-*-soft`, kenar `status-*-border`.
