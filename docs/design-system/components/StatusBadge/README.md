# StatusBadge

Statü rozeti: glyph + metin + tonlu zemin — renk, glyph ve metin üçü birden.

**Tüketici sağlar:** `status`; isteğe bağlı `label` (varsayılanı `STATUS_META`'daki uygulama adıdır; `To build` ya da `Marked to build` gibi duruma özgü kelimeyi ver) ve `detail` (süre, sayaç — mono).

**Props:** `status` · `label` · `size` `sm | md` · `detail` · `style`. Zemin `status-*-soft`, kenar `status-*-border`.
